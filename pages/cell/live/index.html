    Assembly cell, live

    A robot assembly cell, simulated: four six-axis arms on a ring round a work zone, a tool rack beside each, a tray of parts, a rotary stage with a vise, a microscope on a gantry. The simulator -- kinematics, timed moves, collision along every motion, grasping, falling -- runs in this page, compiled to WebAssembly, with X_eTaL beside it; a Three.js player draws the cell's timeline.

    Every control writes a command in the cell's command language and runs it, as the command box does: tool A tweezers, pick A U1 grasp=ends, place A U1 at=0,0,-32, vise close, release A U1, move A to=0,120,60, stage turn=90. A command that cannot start is refused and changes nothing; one that meets something stops there and says what touched what. A dry run changes nothing; Rewind goes back to the scrubber's time, keeping what came after on the timeline, marked.

    Units are millimeters and degrees, Z up, the work zone at 0 0 0. The design: docs/cell-design.md in the repository.
