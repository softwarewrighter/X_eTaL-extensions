libraryextensions/blender/lib/Blender.xtl

Blender.xtl -- the facade of the blender extension: Blender 3D in batch, driven from X_eTaL. A program writes the Python -- a launcher that runs Blender in the background, and the bpy script Blender runs inside -- with bl:w_rite!, runs the launcher with bl:r_un! (python3, with XETAL_BLENDER set to the Blender found), and lists what it made with bl:f_iles. Paths are under the working directory (or XETAL_BLENDER_ROOT). Import: "bl:" u_se< "Blender" Run with xetal-x (xetal-x --ext DIR puts this directory on XETAL_PATH). Each signature line is written out by the binding macro (lib/Ffi.xtlm).
