libraryextensions/blender/lib/Bpy.xtl

Bpy.xtl -- Blender's Python (bpy) written by X_eTaL: each function returns a piece of a script as text, and a program joins the pieces into the script Blender runs inside (written with bl:w_rite!, run by the launcher bp:launcher through bl:r_un!). The geometry is X_eTaL's: a set of cubes is worked out as arrays -- every corner, every face -- and written into the script as numbers, one mesh for them all. Written for Blender 5.1 (EEVEE is BLENDER_EEVEE; video output is media_type VIDEO). Import: "bp:" u_se< "Bpy"
