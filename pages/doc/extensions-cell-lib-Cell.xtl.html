libraryextensions/cell/lib/Cell.xtl

Cell.xtl -- the facade of the cell extension: a robot assembly cell, simulated -- four arms, a tool rack, trays of parts and a microscope that build circuits in free air, one command at a time (docs/cell-design.md). Import: "ce:" u_se< "Cell" Run with xetal-x (xetal-x --ext DIR puts this directory on XETAL_PATH). Each signature line is written out by the binding macro (lib/Ffi.xtlm, docs/ffi-macro.md).
