libraryextensions/image/lib/Image.xtl

Image.xtl -- the facade of the image extension: PNG and JPEG files as Float arrays from 0 to 1, and back. Gray is h by w, color h by w by 3 (red, green, blue); alpha is dropped. Import: "im:" u_se< "Image" Files are named by paths under the working directory (or XETAL_IMAGE_ROOT), relative, with no .. Run with xetal-x (xetal-x --ext DIR puts this directory on XETAL_PATH). Each signature line is written out by the binding macro (lib/Ffi.xtlm).
