Ffi.xtlm -- the binding macro: a facade function written from the signature of a native function (docs/ffi-macro.md). Import: "ffi:" u_se< "Ffi" (xetal-x puts this directory on XETAL_PATH)

"s_hout : text -> text" ᶠᶠⁱb̲ind< "hello/shout"

expands to the facade function l:s_hout, which speaks the ext: channel (docs/bridge.md). Kinds: unit (no argument), text, chars, int, float (an argument of any rank; as a result, a scalar), and as results also floats and ints (any rank, reshaped by the reply's shape).
