X_eTaL extensions

Libraries extend the vocabulary; macros extend the language; native extensions extend the machine. These are X_eTaL's native extensions: Rust libraries that give programs in X_eTaL, the eXperimental Extensible Typed Array Language, what the language should not reinvent -- a database, a clock -- behind ordinary typed X_eTaL libraries. The live pages run with the Rust compiled to WebAssembly: edit a program and run it again.

clock

Wall-clock and monotonic time, which X_eTaL does not have (docs/xetal-asks.md in the repository, E4): timestamps for programs, and timing for benchmarks -- including the cost of the bridge itself.

live in your browser

hello

The smallest X_eTaL native extension. It exists to prove the boundary: each function exercises one thing a real extension needs.

live in your browser

sqlite

SQLite databases for X_eTaL: run statements, and bring query results back as X_eTaL arrays -- numbers as a matrix to compute on, text as a Char matrix -- through rusqlite with SQLite compiled in.
