X_eTaL extensions

Native Rust extensions for X_eTaL, the eXperimental Extensible Typed Array Language, compiled to WebAssembly and running in your browser: each page runs an X_eTaL program that calls Rust through an ordinary X_eTaL library. Edit the program and run it again.

clock

Wall-clock and monotonic time, which X_eTaL does not have (docs/xetal-asks.md in the repository, E4): timestamps for programs, and timing for benchmarks -- including the cost of the bridge itself.

hello

The smallest X_eTaL native extension. It exists to prove the boundary: each function exercises one thing a real extension needs.
